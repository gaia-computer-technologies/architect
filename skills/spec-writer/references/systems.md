# Specification systems (orientation only)

_Last reviewed: 2026-11. Codes, editions, and platforms change. Confirm against the practice's licensed master before using any section reference._

Ask which system the practice uses. These are the common ones; there are many national variants.

| Region | System | Structure in brief |
|---|---|---|
| UK | NBS (NBS Chorus platform), classified with **Uniclass** (Systems "Ss_", Products "Pr_" tables). Older practices still use the legacy CAWS work-section structure. | Clauses grouped by system; system outline, then performance, products, execution, completion. |
| US / Canada | **MasterFormat** (CSI) for section numbering, **SectionFormat** for the three-part section (Part 1 General, Part 2 Products, Part 3 Execution), **PageFormat** for layout. Canada also uses the National Master Specification (NMS). | Divisions and six-digit section numbers. |
| Australia | **NATSPEC** | Worksections with general, materials, execution content. |
| New Zealand | **Masterspec** | Similar worksection model. |
| Netherlands | **STABU** | Chapter-based standard system used widely in Dutch tender documents. |
| Germany | **StLB-Bau** (standard performance texts) with **VOB/C** (ATV DIN 18299 onward) as the technical contract conditions | Bill-of-quantities style (Leistungsverzeichnis); text and quantities together. |
| France | **CCTP** (Cahier des clauses techniques particulières), per lot | Per trade package (lot), referencing DTU technical documents. |
| International / other | Often a project-specific system, or one of the above adopted locally | Ask for the practice's template. |

## How to use this

- Use the system's own structure and terminology for the clause.
- Never write a section code you can't confirm. Use "[section ref: confirm in master]".
- Where a standard is referenced (EN, ISO, ASTM, BS, DIN, AS/NZS), name it only when a source document gives it, and note the edition the source uses.
