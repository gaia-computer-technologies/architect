# Where code text lives

_Last reviewed: 2026-11. Access models change. If this is much older than today, say so and re-check._

These are places to retrieve clause text. Record the edition and access date for every quote.

## Why retrieval is mandatory

- UpCodes reported that generic LLMs answered building-code questions correctly about 36% of the time in its own testing (https://up.codes/features/copilot, vendor-reported). Treat any clause recalled from model memory as unverified.

## By jurisdiction (starting points)

- **England:** Approved Documents and the Building Regulations are published by government on gov.uk. Check the amendment year and any transitional provisions for the application date.
- **Scotland / Wales / Northern Ireland:** separate regimes with their own technical handbooks or guidance. Don't apply English documents.
- **United States:** model codes (IBC, IRC, IECC and others) published by the International Code Council, adopted by states and municipalities with amendments. Code-hosting services such as UpCodes and the ICC's own digital codes show adopted versions for many jurisdictions. Confirm local amendments with the authority having jurisdiction.
- **EU member states:** national building codes, usually referencing Eurocodes and harmonised EN standards. Each state publishes its own code; standards are sold by national standards bodies.
- **Australia:** the National Construction Code (NCC), published by the Australian Building Codes Board, with state variations.
- **Elsewhere:** ask the architect which code is in force and where they access it.

## Standards

- ISO, EN, BS, DIN, ASTM, NFPA and similar standards are usually licensed. If the practice has access, ask them to paste the clause; otherwise list it as "text not retrieved".
